## 本专题关注什么

DeepSeek 的官方 API、开放权重和社区工具是不同交付形式。权重开放不代表托管 API 免费，社区桌面端也不等于官方客户端。比较能力与成本前，需要确认模型标识、运行方式和提供服务的主体。

本专题关注模型更新、推理与多模态能力、开发工具和计费规则。价格报道应结合生效时间、缓存命中、输入输出及高低峰条件阅读，不宜只比较单个数字。

## 官方资料入口

- [DeepSeek 官方网站](https://www.deepseek.com/)：官方产品与服务入口。
- [DeepSeek API 文档](https://api-docs.deepseek.com/zh-cn/)：模型接口、更新与计费说明。
- [DeepSeek GitHub](https://github.com/deepseek-ai)：官方代码与项目资料。
