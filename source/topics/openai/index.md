## 本专题关注什么

OpenAI 的产品消息通常涉及不同层次：ChatGPT 是面向用户的产品，模型 API 面向开发者，而 Codex 聚焦编程与任务执行。相同模型名称不意味着这些入口具有相同权限、计费方式或功能。

阅读更新时，优先确认“哪个入口、哪些账号、什么地区、何时生效”。厂商公告中的计划与预览，不应被理解为所有用户已经可用。

## 官方资料入口

- [OpenAI 官方网站](https://openai.com/)：产品与研究公告。
- [OpenAI 帮助中心](https://help.openai.com/)：账号、套餐、地区与功能说明。
- [OpenAI 开发者文档](https://developers.openai.com/)：接口、模型与开发工具资料。
