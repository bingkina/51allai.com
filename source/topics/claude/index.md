## 本专题关注什么

Claude 模型、Claude 网页产品与 Claude Code 属于不同使用入口。模型发布、订阅开放和 API 接入可能在不同时间发生，不能仅凭某个模型名称判断自己的账号是否可用。

本专题重点记录编程与知识工作能力、工具调用、用量和安全规则。涉及基准成绩时，区分厂商披露与独立复现；涉及敏感权限时，以产品文档和实际授权范围为准。
