> 小米于 2026 年 9 月 8 日开放 Xiaomi MiMo Desktop 邀测。审核通过的用户可限时、限量、免费体验 MiMo-X-Pro-Preview 与 MiMo-X-Flash-Preview；客户端面向办公、编程、设计和调研任务，生成结果可预览、继续编辑和回退版本。
![Xiaomi MiMo Desktop 邀测与 MiMo-X 预览模型](https://images.51allai.com/blog/xiaomi-mimo-desktop-invite-test-cover_20260908_190312.png)

## 从聊天窗口转向可编辑成果

MiMo Desktop 是一款面向工作任务的桌面 AI 应用。用户可以直接导入表格、图片、视频、PDF、录音和压缩包，用自然语言说明目标，再由客户端拆解步骤并调用工具执行。

它交付的内容不只是一段回答，还包括可继续修改的文档、表格、幻灯片、网页、图片、音频、视频、3D 模型、App 和软件工程项目。成果可以直接在会话中预览；网页和演示类内容还可点击操作，不需要先搭建本地前端环境。

## 局部修改和 Smart 调度进入同一工作台

生成成果后，用户可以选中文本、图表或表格区域，再描述修改要求。客户端只处理选定范围，并保留不同版本，方便比较和回退。

内置的 Smart 调度会评估任务类型、复杂程度、交付要求和执行成本，在不同模型、Agent 与执行框架之间选择路径。大型任务还可以拆给多个 Agent，分别处理调研、规划、执行和复核。用户不必在开始任务前手动决定模型或工作流。

## 浏览器操控与电脑操控有版本差异

MiMo Desktop 可以控制浏览器，完成打开网页、检索信息、填写表单和提取素材等操作。网页中的信息可以直接进入当前任务，生成网页后也能在同一流程里检查关键交互。

更进一步的电脑操控包括读取屏幕、操作键盘和鼠标，以及跨应用传递信息。这项能力仅限海外版；国内版不能按海外版的桌面跨应用能力来理解。

## 国内外用户均可提交申请

国内用户可前往 [MiMo Desktop 国内邀测页](https://mimo.xiaomimimo.com/desktop/invite/) 提交申请，海外用户使用 [海外邀测页](https://mimo-ai.xiaomimimo.com/desktop/invite/)。审核通过后才能下载和使用客户端，现阶段优先向 Xiaomi MiMo 开放平台已有用户开放。

邀测期间提供的两款模型是 MiMo-X-Pro-Preview 和 MiMo-X-Flash-Preview。它们仍属于 Preview 版本，本次开放的是申请通道，不是无需审核即可下载的公开测试。

与此前面向开发者的 [MiMo-V2.5 API 与 Token Plan](https://www.51allai.com/posts/2026/05/xiaomi-mimo-v25-api-price-cut/) 不同，MiMo Desktop 把模型、工具调用、成果预览和修改放进一个桌面工作台，普通用户不需要先接入 API 才能参与这次邀测。
