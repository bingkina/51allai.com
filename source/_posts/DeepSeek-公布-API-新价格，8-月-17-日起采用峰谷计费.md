> DeepSeek 将于北京时间 2026 年 8 月 17 日 0 时启用 API 新价格。V4 Flash 与 V4 Pro 都改为峰谷计费，高峰时段为 9:00–12:00 和 14:00–18:00，其余时间的空闲价为高峰价的一半。
![DeepSeek V4 API 峰谷计费与 8 月 17 日新价格](https://images.51allai.com/blog/deepseek-api-peak-off-peak-pricing-cover_20260813_202908.png)

## 8 月 17 日起分两个时段计费

DeepSeek API 新价格将在北京时间 2026 年 8 月 17 日 0 时生效。高峰时段是 9:00–12:00 和 14:00–18:00，其余时间划为空闲时段。同一款模型、同一类 Token 在空闲时段的单价是高峰时段的一半。

API 按 Token 计费。Token 是模型处理文字时使用的计量单位，一个汉字、英文单词片段、数字或标点都可能占用 Token。账单将输入与输出分开计算，输入又根据是否命中缓存分为两档。

## V4 Flash 和 V4 Pro 新价格

下表价格均为人民币，计费单位是每 100 万 Token：

| 模型与时段 | 输入（缓存命中） | 输入（缓存未命中） | 输出 |
| --- | ---: | ---: | ---: |
| V4 Flash·空闲 | 0.05 元 | 1.5 元 | 4.5 元 |
| V4 Flash·高峰 | 0.10 元 | 3.0 元 | 9.0 元 |
| V4 Pro·空闲 | 0.15 元 | 4.5 元 | 13.5 元 |
| V4 Pro·高峰 | 0.30 元 | 9.0 元 | 27.0 元 |

缓存命中指请求的前缀与之前处理过的内容一致，平台可以复用已完成的计算。固定的系统提示词、工具说明和长文档前缀都可能形成可复用内容。请求前缀发生变化后，对应的输入会按缓存未命中单价计算。

## 等量输入和输出的成本变为两倍或四倍

8 月 17 日之前，V4 Flash 每 100 万 Token 的缓存命中输入、缓存未命中输入和输出价格分别为 0.02 元、1 元和 2 元；V4 Pro 对应为 0.025 元、3 元和 6 元。

如果一项任务消耗 100 万 Token 的缓存未命中输入，并生成 100 万 Token 输出，V4 Flash 的成本会从 3 元变为空闲时段 6 元、高峰时段 12 元。V4 Pro 会从 9 元变为空闲时段 18 元、高峰时段 36 元。在这组等量输入和输出算例中，空闲时段总成本是旧价的两倍，高峰时段是旧价的四倍。

各计费项的涨幅并不相同。V4 Flash 和 V4 Pro 的缓存未命中输入空闲价都比旧价高 50%，输出空闲价高 125%。V4 Flash 缓存命中输入的空闲价从 0.02 元升至 0.05 元，V4 Pro 则从 0.025 元升至 0.15 元。

## 批处理任务可以改到空闲时段

对实时客服、交互式编程和在线智能体任务，请求时间通常由用户行为决定，预算应按高峰价格保留余量。批量摘要、离线分析、索引更新和定时内容处理可以改到空闲时段执行，同等 Token 用量的价格为高峰时段的一半。

调整任务时间之外，开发者还可以将稳定的系统提示词和工具定义放在请求前部，减少前缀的无意义变化，并分开记录缓存命中输入、缓存未命中输入和输出的实际 Token 用量。价格不宜直接写死在业务逻辑中，使用独立配置更方便更新预算和告警阈值。

## API 调价不等于网页端和 App 收费

这次新价格针对使用 API Key、按 Token 扣费的 DeepSeek API 服务。它与用户直接打开 DeepSeek 网页或 App 对话不是同一个销售入口。普通用户不需要把 API 单价变化直接换算成客户端订阅或对话费用。
