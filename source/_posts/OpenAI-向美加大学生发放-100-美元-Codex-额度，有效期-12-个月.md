> OpenAI 面向美国和加拿大符合条件的在校大学生发放 100 美元 Codex 额度，验证通过后自动进入个人 ChatGPT 工作区，自发放日起 12 个月内有效。该权益只扩展 Codex 用量，不是 ChatGPT Plus 免费订阅，也不是 API 额度。
![OpenAI 美加大学生 100 美元 Codex 额度封面](https://images.51allai.com/blog/openai-student-codex-credits-cover_20260812_150340.png)

## 100 美元是 Codex 额度，不是 Plus 订阅

这项学生权益会向通过验证的 ChatGPT 账户加入 2,500 点额度，折合 100 美元。额度用于在账户原有套餐限额之外继续使用 Codex，不能抵扣 OpenAI API 调用费用。

Codex 是用于软件开发的编码智能体，可以阅读和修改代码、运行命令、检查问题并协助交付项目。学生可以用它完成课程项目、理解陌生代码库、排查报错或编写测试，但每项任务消耗的用量会随代码规模和复杂程度变化。

领取权益不会把账户升级为 ChatGPT Plus。ChatGPT Free、Go、Plus 或 Pro 用户都可以参加，验证通过后得到的是一笔额外的 Codex 使用额度，账户原有套餐保持不变。

## 谁可以领取

领取者需要同时满足几项条件：当前就读于美国或加拿大能够授予学位的大学；领取时居住在美国或加拿大；通过学生身份验证。每名学生只能领取一次。

学生可以使用个人 ChatGPT 账户参加，不需要把整个账户改成学校工作区。验证过程中需要使用大学邮箱证明在读身份。若账户中有多个工作区，额度会进入与教育验证关联的个人工作区。

## 如何领取和开始使用

符合条件的学生可打开 `https://chatgpt.com/codex/offers/students`，登录准备使用的 ChatGPT 账户，再通过 SheerID 完成学生身份验证。审核通过后，2,500 点额度会自动加入账户，余额可在用量页面查看。

Codex 不需要单独注册账户，使用现有 ChatGPT 登录信息即可。学生可以在 Codex 应用、命令行工具、IDE 扩展或网页版中使用它。IDE 是集成开发环境，例如 Visual Studio Code；扩展安装后，用户可以在写代码的窗口中直接向 Codex 分配任务。

使用 Codex 云端功能时需要通过 ChatGPT 登录。只用 API 密钥进行身份验证，不能领取或使用这项学生额度。

## 12 个月指额度有效期

12 个月从额度发放之日开始计算，不是一个自然学年，也不是 12 个月的 Plus 会籍。到期后，未使用的余额会失效；如果提前用完，用户可以自行购买更多额度继续扩展 Codex 用量。

对学生来说，领取前最需要确认的是账户和学校邮箱。验证应在最终准备使用的 ChatGPT 账户中完成；额度发放后不能转到另一个账户。
