> Computer History 已加入 ChatGPT macOS 应用，可让 ChatGPT 与 Codex 在用户授权后引用应用和网站活动，继续处理尚未完成的工作。功能默认关闭，不截屏、不录音，现面向 Pro、Business 和 Enterprise 用户开放。用户还可暂停记录、筛选应用与网站，并检查或删除时间线项目。
![ChatGPT 和 Codex Computer History Mac 活动时间线](https://images.51allai.com/blog/chatgpt-codex-computer-history-cover_20260814_121116.png)

## Computer History 引用的是用户选定活动

Computer History 是 ChatGPT macOS 应用里的可选功能。用户开启后，ChatGPT 与 Codex 可以引用来自应用和网站的指定活动，用来补足当前任务的上下文。例如，一项工作跨越多个应用时，用户不必在新对话里重新输入所有背景，可以让产品参考已授权的活动接着处理。

这不等于 ChatGPT 或 Codex 自动读取 Mac 上的全部内容。用户可以选择哪些应用和网站纳入记录，也可以随时暂停 Computer History。

## 记录交互事件，不截屏也不录音

Computer History 记录的是交互事件，不是屏幕截图或录屏。它也不采集麦克风输入和系统音频。浏览器的隐私浏览活动不会进入 Computer History。

用户可以检查已生成的时间线项目，并删除不想保留的项目。这些控制与“选择哪些应用和网站可被引用”一起，决定了 ChatGPT 和 Codex 能从哪些 Mac 活动中取得上下文。

## 目前仅面向部分套餐和地区

Computer History 当前面向 ChatGPT Pro、Business 和 Enterprise 用户开放，并且默认处于关闭状态。Pro 用户需要自行选择开启；Business 和 Enterprise 工作区则需要管理员先授予使用权限，成员才能自愿开启。

该功能发布时不向欧洲经济区、英国和瑞士开放。它又是 macOS 客户端功能，因此“ChatGPT 和 Codex 已加入 Computer History”并不代表所有平台、所有套餐都能直接使用。
