> SpaceXAI 于 8 月 12 日发布 Grok 4.6，面向多步骤智能体任务。模型支持 50 万 Token 上下文和文字、图片输入，已进入 Cursor、Grok Build、API 及合作平台。API 输入价格从每百万 Token 2 美元起。
![Grok 4.6 长程智能体多步骤任务流程](https://images.51allai.com/blog/spacexai-grok-46-agent-cover_20260813_103553.png)

## 把一次问答扩展为多步骤工作

Grok 4.6 的重点不是增加一个新的聊天入口，而是处理持续时间更长、步骤更多的任务。它面向资料研究、信息分析、代码库处理，以及从产品想法到可运行应用的工作流程。

这里的“长程智能体”指模型需要在同一项工作中连续完成规划、调用工具、修改内容和检查结果，而不是收到一个问题后只返回一段文字。对普通用户来说，差别主要体现在任务规模：可以把一份需要反复拆解和推进的工作交给模型，而不是把每个步骤分别复制到多个对话中。

对于开发者，代码库级任务是更直接的使用场景。模型可以在多个文件和多轮操作之间保持任务上下文，用于研究现有项目、修改代码和制作应用初版。产品设计和视觉项目也属于本次发布覆盖的范围，但实际可交付结果仍取决于提示词、工具权限、运行环境和任务本身。

## 支持 50 万 Token 上下文和图片输入

Grok 4.6 提供 50 万 Token 上下文窗口。Token 是模型处理文字时使用的计量单位；更大的上下文可以容纳更多代码、文档和对话记录，适合一次读取较大的项目材料。

模型接受文字和图片输入，输出为文字。图片输入可用于分析截图、图表或视觉素材，再把识别结果带入后续步骤。通过 Vercel AI Gateway 调用时，可以选择 low、medium、high 和 xhigh 四档推理强度，默认使用 high；模型标识为 `xai/grok-4.6`。

50 万 Token 表示单次请求可容纳的最大上下文规模，不等于每次任务都需要把窗口用满。长输入会增加 Token 消耗，也会影响调用成本和响应时间。开发者应按实际文件量和任务复杂度控制输入，而不是把所有资料一次性塞进请求。

## 已进入 Cursor、Grok Build 和 API

Grok 4.6 已在 Cursor 和 Grok Build 上线，也可以通过 SpaceXAI API、OpenRouter、Vercel 和 Cloudflare 调用。使用 Cursor 或 Grok Build 的用户可以直接在产品内选择模型；自行开发应用的团队可以走 API 或已接入的模型平台。

API 起价为每百万输入 Token 2 美元、每百万输出 Token 6 美元。速度更快的版本价格是标准版本的两倍。这里的价格是起步费率，实际账单还取决于使用的平台、请求长度、缓存和输出量，比较成本时应查看具体入口的计费页面。

发布首周，Cursor 和 Grok Build 为 Grok 4.6 提供两倍套餐内含用量。这是产品内的限时额度，不是 API 账户通用充值，也不代表所有合作平台都会同步增加额度。

## 哪些人可以直接尝试

已经使用 Cursor 的开发者可以把 Grok 4.6 用在代码理解、跨文件修改和应用原型任务中。需要把模型接入自有产品的团队，可以通过 API 或合作平台调用，并根据任务选择推理强度、上下文长度和输入模态。

普通用户如果没有 API 开发需求，可以从 Grok Build 体验由想法生成应用或工作成果的流程。第一次尝试时，适合选择边界清楚、结果容易检查的任务，并把验收条件写进指令，例如必须运行测试、检查页面状态或输出指定格式的文件。
