> OpenAI 调整 ChatGPT 的 GPT-5.6 使用范围。Plus 与 Pro 的 Instant 与深度推理统一由 Sol 驱动；Free 与 Go 将把 Luna 设为默认模型，并开放受滥用防护约束的不限量文字聊天。文件、图片和其他工具仍有限额。
![ChatGPT GPT-5.6 Sol 与 Luna 套餐调整封面](https://images.51allai.com/blog/chatgpt-gpt-56-sol-luna-access-cover_20260807_104523.png)

## Plus 与 Pro 的快速回答和深度推理统一使用 Sol

OpenAI 于 8 月 6 日调整 ChatGPT 的模型分配。Plus 与 Pro 用户在普通聊天中使用 Instant 快速回答或提高推理强度时，背后都由 GPT-5.6 Sol 驱动。Instant 是适合日常问答的快速入口，深度推理则让模型为规划、研究、写作、编程和复杂决策投入更多处理时间。

这两个套餐同时获得新的推理强度滑块。用户可以在 ChatGPT 网页版、移动端和桌面端直接调节：简单问题保持快速回答，需要多步分析时再提高强度。调整发生在同一个 Sol 模型内，不需要为了改变思考时间切换到另一款模型。

## Free 与 Go 将默认使用 Luna

Free 与 Go 用户的普通聊天将分阶段把 GPT-5.6 Luna 设为默认模型。Luna 是 GPT-5.6 系列中面向高频使用的轻量型号，这次更新把它带到日常 ChatGPT 对话中。

两类用户还将获得不限量文字聊天，以及处理较难问题的 Think 按钮。按下 Think 后，Luna 会花更多时间组织答案。这里的“不限量”只指普通文字聊天，并受防滥用机制约束；文件上传、图片和其他工具仍有各自限额。因此，Free 与 Go 的整体功能和使用额度并没有变成完全相同。

## ChatGPT Work 和 Codex 不受此次更新影响

这次调整只针对 ChatGPT 的 Chat 对话体验。ChatGPT Work 和 Codex 使用的 GPT-5.6 Sol 版本没有随之更新，原有模型分配继续保留。

在这两个工作场景中，Free 与 Go 用户仍使用 GPT-5.6 Terra；Plus、Pro、Business 与 Enterprise 用户仍可在 Sol、Terra 和 Luna 之间选择。普通聊天中的 Luna 默认模型与不限量文字对话，不能直接套用到 Work、Codex 或 API 用量上。

## 用户如何使用新入口

Plus 与 Pro 用户可以在普通聊天里使用新的滑块控制回答强度。日常问答可保持快速设置，长文分析、复杂计划或多步推理再提高强度。

Free 与 Go 用户无需手动选择 Luna；更新到达账户后，普通聊天会默认使用它。遇到需要更多推理的问题时，可点按 Think 按钮。使用文件、图片或其他工具前，仍需查看界面显示的对应额度。
