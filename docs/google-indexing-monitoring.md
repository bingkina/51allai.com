## 判定标准

- News sitemap 在上线后 24 小时内成功读取。
- 新文章发布 7 天内出现 Googlebot 抓取日期。
- 第 14 天时，5 篇抽样文章至少 3 篇已抓取或已收录。
- 标签页不再新增收录，已收录 URL 中文章页占比持续上升。

若第 14 天抓取率仍低于 50%，再进入外部真实引用、品牌分发和低价值 URL 压缩阶段；不使用批量请求索引或购买链接。

## 内容审计口径

运行 `npm run audit:recent-posts -- 30` 可筛查最近 30 天文章的外部参考链接、影响/对比类标题和正文站内链接。脚本只能找出候选问题，官方或第一方来源、事实与判断的区分仍需人工核验。

本轮 5 篇优先文章分别对应独立产品或事件，不存在同一产品 7 天内核心事实高度重叠的情况，因此未合并 URL，也未新增 301。后续如合并文章，必须先在 `source/_redirects` 添加旧 URL 到保留 URL 的 301。
